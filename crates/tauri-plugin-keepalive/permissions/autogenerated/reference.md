## Default Permission

Default permissions for the Echoo keepalive plugin

#### This default permission set includes the following:

- `allow-start`
- `allow-stop`
- `allow-status`
- `allow-handoff`
- `allow-prepare-notifications`
- `allow-show-notification`
- `allow-open-notification-settings`
